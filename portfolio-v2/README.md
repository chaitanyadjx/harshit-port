# Harshit Kumar Mishra - Portfolio V2 (Bruno Simon 3D Engineering Cockpit)

This folder contains the transformed **"Main Character" 3D Engineering Portfolio** featuring:
- **Interactive UAS Quadcopter Drone Cursor**: dynamic flight banking physics, spinning rotor blades, telemetry HUD tag, and targeting reticle.
- **Bruno-Simon-Style 3D Mechanical Cockpit**: Real-time interactive 3D assembly (Planetary gearbox with 10:1 ratio + 4x UAS drone propulsion system).
- **Interactive CAD Disassembly (Exploded View)**: Smooth component separation with leader lines and CAD telemetry.
- **3600 RPM Turbo Mode**: Dynamic rotational velocity and energy spark particle system.
- **Web Audio FX Synthesizer**: Zero-dependency mechanical clicks and drone throttle audio effects.
- **Framer Motion Micro-Interactions**: Animated stats counters, fluid sliding tab indicator, 3D perspective tilt cards with cursor-reactive glow.

## How to run:
```bash
cd portfolio-v2
npm install
npm run dev
```
